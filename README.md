# Sales Performance Analysis Using Power BI

## Project Overview
This project focuses on analyzing sales data using
Microsoft Power BI to identify business performance,
sales trends, and profit insights.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Power Query

## Dashboard Features
- Total Sales and Total Profit
- Completed Orders and Units Sold
- Monthly Sales Analysis
- Product Category Analysis
- Regional Performance Analysis
- Interactive Slicers and Filters

## Project Files
- Dashboard: Power BI dashboard (.pbix)
- Dataset: Excel dataset (.xlsx)
- docs: Dashboard screenshots


## Conclusion
This project helped me develop practical skills in
data cleaning, data analysis, DAX calculations,
and interactive dashboard development.
